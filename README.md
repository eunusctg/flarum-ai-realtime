# Flarum AI Realtime Extension

AI-powered real-time features for Flarum including live discussions, smart moderation, and AI assistance.

## Features

- 🔥 Real-time discussions and notifications
- 🤖 AI-powered content moderation
- 📝 Smart reply suggestions
- 🌐 Automatic translation
- 📊 Sentiment analysis
- 📚 Content summarization

## Installation

```bash
composer require eunusctg/flarum-ai-realtime
